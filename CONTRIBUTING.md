# Contributing

Thanks for your interest in contributing to Lynx.

## Getting Started

1. Fork the repository
2. Clone your fork locally
3. Set up the development environment — see [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)
4. Create a branch for your changes

## Submitting Changes

- Open a pull request against `main`
- Describe what you changed and why
- Link any related issues
- Make sure CI passes

## Bug Reports

When reporting bugs, include:

- Steps to reproduce
- Expected vs. actual behavior
- Lynx version (or commit hash)
- Docker version and host OS
- Relevant logs (`docker compose logs lynx`)

## Feature Requests

Open an issue describing the feature you'd like to see. Explain the use case — it helps prioritize and design the right solution.

## Code Guidelines

- **Backend:** Python with type hints. Follow existing patterns in the codebase.
- **Frontend:** React functional components. Tailwind CSS for styling.
- **Commits:** Write clear, descriptive commit messages.
- **Tests:** Add tests for new functionality when possible.

## Questions?

Open an issue. We're happy to help.
